## 1단계 노트북의 출력

1단계 노트북에는 저자의 컴퓨터(Windows, GPU 없이 CPU)에서 실행한 출력이 들어 있습니다. 경로 구분 기호가 `\` 로 보이는 곳이 있고, 저자 컴퓨터의 폴더 위치는 `…` 로 줄였습니다. Colab에서 실행하면 속도와 일부 수치가 다르게 나옵니다. Colab에서만 도는 셀(GPU 확인, Drive 연결, 화면 띄우기)은 저자 컴퓨터에서 실행하지 않아 출력이 없습니다. 2장 노트북은 모두 그런 셀입니다.
